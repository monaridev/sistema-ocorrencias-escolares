Sistema de Ocorrências Escolares

Aplicativo criado para registrar ocorrências escolares, gerar documentos administrativos e enviar esses documentos por e-mail.

O sistema utiliza a Gmail API exclusivamente para enviar e-mails autorizados pelo usuário. Ele não lê, modifica ou exclui mensagens da caixa de entrada.

Política de Privacidade

Projeto educacional desenvolvido para a E.E. João Paulo II.
