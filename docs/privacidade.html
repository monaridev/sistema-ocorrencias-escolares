Política de Privacidade

Última atualização: 8 de setembro de 2026.

1. Finalidade do sistema

O Sistema de Ocorrências Escolares é um projeto educacional destinado ao registro de ocorrências escolares e à geração e envio de documentos administrativos relacionados a esses registros.

2. Uso da Conta Google e da Gmail API

O aplicativo utiliza a Gmail API exclusivamente para enviar e-mails gerados pelo próprio sistema após autorização do usuário.

O único escopo Google solicitado para essa finalidade é https://www.googleapis.com/auth/gmail.send.

O aplicativo não solicita permissão para ler a caixa de entrada, consultar mensagens, modificar mensagens ou excluir mensagens da Conta Google do usuário.

3. Dados utilizados

Para realizar o envio autorizado, o sistema processa apenas os dados necessários para compor a mensagem, seus destinatários e os documentos gerados pelo aplicativo. As credenciais OAuth são usadas somente para autenticar o envio perante a Gmail API.

4. Compartilhamento de dados

Os dados obtidos por meio das APIs do Google não são vendidos nem utilizados para publicidade. O sistema não compartilha dados da Conta Google com terceiros, exceto quando isso for estritamente necessário para executar o serviço solicitado pelo próprio usuário ou para cumprir obrigação legal.

5. Armazenamento e segurança

Tokens de autenticação e outras credenciais não devem ser incluídos em repositórios públicos. O projeto utiliza esses dados somente para manter a autorização necessária ao envio de e-mails.

6. Revogação de acesso

O usuário pode revogar o acesso concedido ao aplicativo a qualquer momento pelas configurações de segurança da própria Conta Google. Após a revogação, o aplicativo deixa de conseguir enviar e-mails em nome dessa conta até que uma nova autorização seja concedida.

7. Contato

Dúvidas relacionadas à privacidade ou ao uso da integração com o Google podem ser encaminhadas ao e-mail de suporte informado na tela de consentimento OAuth do aplicativo.
